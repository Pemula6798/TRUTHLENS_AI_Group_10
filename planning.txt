2. UPDATE ARSITEKTUR MODEL (Dua Kepala Output)
------------------------------------------------------
Ganti penggunaan `AutoModelForSequenceClassification` dengan `AutoModel` dasar, lalu buat dua layer klasifikasi terpisah.

```python
class MTLTransformerClassifier(nn.Module):
    def __init__(self, model_name):
        super().__init__()
        from transformers import AutoModel
        self.encoder = AutoModel.from_pretrained(model_name)
        
        hidden_size = self.encoder.config.hidden_size
        
        # Kepala 1: Fake/Real
        self.veracity_head = nn.Sequential(
            nn.Dropout(0.1),
            nn.Linear(hidden_size, 2)
        )
        
        # Kepala 2: Human/AI
        self.origin_head = nn.Sequential(
            nn.Dropout(0.1),
            nn.Linear(hidden_size, 2)
        )

    def forward(self, **kwargs):
        outputs = self.encoder(**kwargs)
        # Ambil representasi token [CLS]
        pooled_output = outputs.last_hidden_state[:, 0, :]
        
        veracity_logits = self.veracity_head(pooled_output)
        origin_logits = self.origin_head(pooled_output)
        
        return veracity_logits, origin_logits
```

3. UPDATE FUNGSI TRAINING (Kombinasi 2 Loss)
------------------------------------------------------
Ubah `train_transformer` agar menghitung dua Error/Loss dan menggabungkannya.

```python
# Di dalam loop training:
veracity_out, origin_out = model(**enc)

loss_fake = criterion(veracity_out, label_fake)
loss_ai = criterion(origin_out, label_ai)

# Gabungkan loss (bisa disesuaikan bobotnya, misal 0.5 dan 0.5)
total_loss = loss_fake + loss_ai
total_loss.backward()
```
